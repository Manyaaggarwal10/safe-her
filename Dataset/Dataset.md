# 📊 Dataset Documentation

## Dataset Name

**Indian Crimes Dataset **

---

## Source

- **Platform:** Kaggle
- **Dataset Link:** https://www.kaggle.com/datasets/sudhanvahg/indian-crimes-dataset

---

## Overview

The Indian Crimes Dataset is a publicly available dataset containing over **40,000 crime records** from multiple Indian cities between **2020 and 2024**. It captures detailed information about crime incidents, including crime type, location, victim demographics, weapon used, police deployment, and case resolution status. The dataset is suitable for data analysis, machine learning, and crime pattern discovery. :contentReference[oaicite:0]{index=0}

---


## Key Features

The dataset includes attributes such as:

- Crime ID
- Crime Category
- Crime Description
- Crime Domain
- Date Reported
- Date of Occurrence
- Time of Occurrence
- City
- Victim Age
- Victim Gender
- Weapon Used
- Police Deployment
- Case Closed Status
