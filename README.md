# Safe Her- Prediction and Analysis of Crime Against Women in India

## Overview

This project focuses on analyzing crime against women in India using data analytics and machine learning techniques. The objective is to identify crime patterns, understand key influencing factors, and build predictive models that can assist in crime analysis and decision-making.

The project includes data preprocessing, exploratory data analysis (EDA), feature engineering, visualization, and machine learning model development.

---

## Features

- Data Cleaning and Preprocessing
- Missing Value Handling
- Outlier Detection
- Exploratory Data Analysis (EDA)
- Univariate and Bivariate Analysis
- Feature Engineering
- Data Visualization
- Machine Learning Model Training
- Model Evaluation
